# ONE SEA, ONE LIFE ⚓
## 출생부터 마지막 항해까지 — 대해적시대 인생 시뮬레이터

4대 바다 중 어딘가에서 태어나 성장하고, 해적·해군·혁명군·현상금 사냥꾼·상인·모험가로 살아갑니다. 웹 브라우저만 있으면 플레이할 수 있는 비공식 팬 창작 게임입니다.

[80억 분의 1 (1in8b.life)](https://1in8b.life/ko/)의 **무작위 출생 → 성장 → 인생의 갈림길 → 생애 회고**라는 장르적 진행 방식에 영감을 받았습니다. 원본 사이트의 코드, 이미지, 문구, 데이터, 통계 시스템을 복제한 것은 아니며 별도의 게임 엔진과 오리지널 시나리오를 제작했습니다.

## 실행

- **IDE 불필요:** Code → Download ZIP으로 내려받은 뒤 압축을 풀고 index.html을 더블클릭합니다.
- **로컬 서버 (선택):** Python이 설치되어 있다면 저장소 루트에서 아래 명령을 실행합니다.

~~~bash
python -m http.server 8000
~~~

이후 http://localhost:8000/ 에 접속합니다.

- **GitHub Pages:** 저장소 Settings → Pages → Deploy from a branch → main / (root)로 설정 후 https://minsung0732.github.io/lifeGameForOnePice/ 에서 실행할 수 있습니다. 배포 설정 전에는 열리지 않을 수 있습니다.

## 플레이 흐름 — 40~60분을 목표로 한 페이싱

기존 '선택 하나 = 1년' 방식은 너무 빠르기 때문에 **한 해 안에 여러 사건을 겪는 방식**으로 변경했습니다.

| 나이 | 사건 턴 / 1년 |
|---|---:|
| 0~5세 | 1 |
| 6~15세 | 2 |
| 16~49세 | 3 |
| 50~79세 | 2 |
| 80세 이상 | 1 |

플레이어는 매 사건을 만나고 선택지 2~4개 또는 직접 입력으로 결과를 결정합니다. 사건을 해결한 뒤 다음 사건으로 넘어갑니다. **6, 12, 16, 22, 30, 50, 65세**의 진로·인생 목표·은퇴 같은 갈림길에서는 자동 진행을 멈추고 직접 선택하게 됩니다.

현재 시간 설계는 대체로 성인까지 살아가는 한 사람의 삶에 **수백 번의 입력과 판단**이 이루어지도록 구성했습니다. 실제 플레이타임 40~60분은 **디자인 목표**이지 측정·보장된 시간이 아닙니다. 플레이 속도와 수명, 읽는 속도에 따라 차이가 납니다. 자동 진행은 5초/9초/12초 간격 중 선택할 수 있으며, 중요한 갈림길에서는 멈춥니다.

## 이벤트 데이터: 121개 오리지널 장면

events.js에는 **105개 기본 사건 + 16개 이전 선택의 여파로 열리는 연쇄 사건**이 있습니다. 각 사건에는 제목, 이야기, 상황에 맞는 **3개의 선택지**, 판정 능력치와 성공/실패 결과가 들어 있습니다.

사건은 출신·나이·역할·위대한 항로 진입 여부·올해 집중 분야·최근 발생 이력에 따라 가중 선택됩니다. 최근 28개의 사건을 회피하며, 서로 다른 삶을 살 때 반복을 줄입니다.

### 사건 분류

- 유년과 가족, 공부, 도장 수련, 친구, 마을 축제
- 항구 노동, 교역, 시장, 항해, 지도와 장비
- 해군의 정의, 해적단의 자유, 혁명군의 신념, 현상금 사냥꾼의 추적
- 위대한 항로의 로그 포스, 캄벨트와 해왕류, 항로 탐험
- 보물 찾기, 뜻밖의 부상, 건강, 노년과 인생의 유산

### 선택의 여파

각 사건의 행동은 능력치·돈·명성·동료·현상금 등을 바꾸며 경험 수치(lifeFlags)도 쌓입니다. 어린 시절에 사람을 도와 쌓은 신뢰가 훗날 도움이 되는 등 특정 경험 조건을 충족하면 **16개의 연결 사건**이 풀립니다. 일부 경험치는 D20 판정 보정에도 영향을 줍니다.

## 그림 라이브러리 — 75개의 SVG

assets/scenes에는 **25개 분류 × 3개 변형 = 75개 독립 창작 벡터 일러스트**를 저장했습니다. 게임 장면의 사건 분류를 바탕으로 자동으로 이미지를 선택하고, 같은 분류가 반복될 때에는 세 가지 색감 및 화면 변형을 순환합니다.

예: 탄생, 집, 학교, 항구, 마을, 도장, 친구, 축제, 시장, 섬, 선박, 해군, 해적, 혁명군, 현상 수배, 항해 지도, 위대한 항로, 보물, 진료소, 작별, 노년, 폭풍, 전투, 악마의 열매, 밤바다.

개별 그림은 같은 파일명으로 교체할 수 있어 향후 권리가 확보된 고품질 이미지로 확장하기 쉽습니다. 공식 원피스 애니메이션 스크린샷이나 저작권 이미지 파일을 포함하지 않습니다.

## 모바일 화면 지원

휴대폰과 태블릿에서 플레이할 수 있도록 기본 데스크톱 디자인 위에 mobile.css 반응형 스타일을 추가했습니다.

- 320px 초소형 화면, 일반 스마트폰, 태블릿 화면의 레이아웃과 줄바꿈 대응
- 모바일 전용 하단 메뉴: **이야기 · 선택지 · 상태 · 기록**
- 손가락 입력용 큰 선택지 버튼 및 단일 열 배치
- 모바일 사건 진행 버튼, 올해의 초점, 자동 진행 속도 재배치
- 이름·건강·베리가 보이는 간결한 상태 표시
- 사건 선택 후 새 이야기로 자동 스크롤 (모바일 한정)
- iPhone 홈 표시줄·노치에 대응하는 safe area 여백, 모바일 글자 입력 시 자동 확대 방지
- 애니메이션 줄이기 설정 존중

직접 휴대폰에서 게임하기: GitHub Pages를 활성화했다면 해당 게임 주소로 접속합니다. 로컬 테스트는 Chrome/Edge의 개발자 도구에서 **기기 에뮬레이션**(320px, 375px, 390px, 430px, 768px)으로 확인할 수 있습니다.
