# GRAND LINE — 당신만의 항해 ⚓

원피스(ONE PIECE) 세계관에서 영감을 얻은 **비공식 팬 제작 브라우저 텍스트 RPG**입니다. 해적, 해군, 혁명군, 현상금 사냥꾼, 상인, 모험가로 캐릭터를 생성해 나만의 항해를 진행할 수 있습니다.

## 게임 시작

1. 캐릭터 이름과 출신 바다(이스트/웨스트/사우스/노스 블루)를 정합니다.
2. 시작 신분을 고르고, 외형 및 무기를 설정합니다.
3. 사건 설명을 읽고 제시된 **2~4개 행동** 중 하나를 고르거나 직접 행동을 입력합니다.
4. 전투, 항해, 탐색, 수련 등에는 **D20 주사위와 능력치 보정**이 적용됩니다.
5. 캐릭터 상태와 최근 항해 기록은 화면에서 확인할 수 있으며 브라우저에 자동 저장됩니다.

## 구현된 기능

- 출신 바다·직업별 게임 도입과 개별 캐릭터 상태
- 턴제 시나리오, 상황별 선택지, 자유 행동 키워드 및 즉흥 판정
- 힘/민첩/맷집/패기를 이용하는 확률 기반 판정
- 전투(공격, 회피 후 반격, 협상, 후퇴), 상처와 회복
- 항해, 폭풍으로 인한 선체 손상, 리버스 마운틴 및 위대한 항로 진입
- 동료 모집, 선술집 소문, 현상 수배범 추적, 시장 거래, 선박 수리, 무기 강화
- 희귀한 오리지널 악마의 열매 발견 및 복용/판매/보관
- 신분별 현상금·해군 계급 변화
- 자동 저장 및 JSON 파일로 내보내기/불러오기
- 모바일·태블릿·데스크톱 반응형 인터페이스

> **현재 버전:** 서버와 외부 API 없이 실행되는 **규칙 기반** 1인용 게임입니다. 자유 입력은 키워드 인식 또는 즉흥 주사위 판정으로 처리되며, 실제 생성형 AI GM이 매 문장을 새로 작성하는 방식은 아닙니다. 열매 설정 중 일부는 팬 창작 요소입니다.

## 사이트 공개하기: GitHub Pages

이 저장소의 main 브랜치 루트에 index.html이 있으므로 별도 빌드 없이 GitHub Pages로 서비스할 수 있습니다.

1. GitHub 저장소의 **Settings** 탭으로 이동합니다.
2. 왼쪽 메뉴 **Pages**를 엽니다.
3. **Build and deployment**에서 Source를 **Deploy from a branch**로 지정합니다.
4. Branch **main**, Folder **/(root)**를 선택해 **Save**를 누릅니다.
5. 배포가 완료되면 [게임 사이트 주소](https://minsung0732.github.io/lifeGameForOnePice/)로 접속합니다.

GitHub Pages 설정이 아직 완료되지 않았다면 사이트 주소는 열리지 않을 수 있습니다.

## 로컬 실행

파일을 다운로드하거나 저장소를 클론한 뒤 다음 명령을 실행합니다.

~~~bash
python3 -m http.server 8000
~~~

브라우저에서 http://localhost:8000 을 열면 됩니다. 별도 패키지 설치나 API 키는 필요하지 않습니다.

## 프로젝트 구성

~~~text
lifeGameForOnePice/
├── index.html  # 캐릭터 생성 + 게임 UI
├── style.css   # 반응형 해양 테마 디자인
├── app.js      # 게임 엔진, 사건, 판정, 저장
└── README.md
~~~

## 저장 데이터

게임 진행 정보는 해당 브라우저의 localStorage에 저장됩니다. 브라우저 데이터를 삭제하면 자동 저장도 함께 사라질 수 있으므로 중요한 캐릭터는 **기록 내보내기**를 통해 JSON 파일로 백업해 주세요. 저장된 데이터는 기본적으로 브라우저 밖으로 자동 전송하지 않습니다.
