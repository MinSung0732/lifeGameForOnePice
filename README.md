# ONE SEA, ONE LIFE ⚓
### 대해적시대에 태어나 한 번의 인생을 살아가는 오리지널 팬메이드 텍스트 게임

원피스(ONE PIECE)의 세계관에서 영감을 얻은 **출생부터 죽음까지의 인생 시뮬레이터**입니다. [80억 분의 1 (1in8b.life)](https://1in8b.life/ko/)의 *무작위 출생 → 시간의 흐름 → 인생의 갈림길 → 생애 회고*라는 장르적인 플레이 흐름을 참고하되, 코드·이미지·문구·음악·통계 엔진을 복제하거나 사용하지 않은 **독립 구현**입니다.

게임 주소(저장소에서 GitHub Pages를 활성화한 뒤):
https://minsung0732.github.io/lifeGameForOnePice/

## 플레이 방법

1. **이름·외형·희망 무기**를 입력합니다(선택 사항). 출신 바다는 기본적으로 운명에 맡기고, 원하면 이스트/웨스트/사우스/노스 블루 중 직접 고를 수 있습니다.
2. 무작위 가정환경과 능력치가 정해지며 **0세부터 인생이 시작**됩니다.
3. 매해 표시되는 네 가지 선택지 중 하나를 골라 한 해를 살아갑니다. 화면 상단에서 올해의 초점을 설정하고 *한 해 보내기* 또는 *자동 진행*을 이용할 수도 있습니다.
4. **6세·12세·16세·22세·30세·50세·65세**에 중요한 선택이 나타납니다. 자동 진행은 결정을 만나면 반드시 멈춥니다.
5. 16세에는 **해적/해군/혁명군/현상금 사냥꾼** 중 선택합니다. **상인**이나 **모험가**는 자유 행동 입력으로 선택할 수 있습니다.
6. 성인이 된 뒤 전투, 폭풍, 모험, 동료, 악마의 열매, 패기, 리버스 마운틴 등 사건이 **허구의 확률 규칙**으로 발생합니다.
7. 죽음을 맞이하면 이번 생의 **인생 결산**과 **생애 연표**를 확인하고 다시 태어날 수 있습니다.

## 주요 시스템

- 출신 바다와 가정환경의 가중 무작위 추첨 (원피스 세계의 **창작 확률**, 실제 공식 설정/통계 아님)
- 1년 단위 턴 진행, 속도 조절 가능한 자동 진행 및 주요 결정 시 자동 정지
- 건강·행복·지식·관계(0~100), 힘·민첩·맷집, 베리·명성·현상금·계급
- 해적·해군·혁명군·현상금 사냥꾼·상인·모험가 진로
- D20 판정에 따른 전투·협상·도주·항해, 부상, 패배 및 사망
- 위대한 항로 진입, 악마의 열매 선택, 패기 수련, 동료, 일과 수입
- 주관식 행동 지원: 입력문에서 의도를 인식하여 행동을 적용. **실시간 생성형 AI GM은 아님**
- 브라우저 localStorage 자동 저장, 인생 종료 시 최대 12개의 지난 삶 기록
- 현재 인생의 JSON 파일 내보내기
- 모바일/PC 반응형 웹사이트

## 로컬 실행

**IDE 없이도** 저장소 ZIP을 내려받고 index.html을 열면 테스트할 수 있습니다.

로컬 HTTP 서버로 실행하려면(선택):

~~~bash
python -m http.server 8000
~~~

그 다음 브라우저에서 http://localhost:8000/ 에 접속하세요.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source: Deploy from a branch**로 설정합니다.
3. **Branch: main / (root)**를 선택한 뒤 저장합니다.
4. GitHub Pages가 게시되면 위 게임 주소로 접속합니다.

## 자동 테스트

GitHub Actions에서 다음 항목을 검사합니다.

- JavaScript 구문 검사 (`node --check app.js`)
- HTML/CSS/JS 파일 존재 여부
- Node VM 기반 게임 스모크 테스트 (`node tests/smoke.js`): 출생, 나이 진행, 갈림길, 진로, 자유 행동, 재접속 후 이어하기, 수명 종료, 전생 기록

## 참고 및 주의

- **1in8b.life**는 현실 세계의 통계를 사용한 실제 인생 시뮬레이터입니다. 이 게임은 해당 데이터를 사용하지 않으며 원피스 세계의 확률을 창작했습니다. 이 프로젝트는 1in8b.life와 협력/제휴 관계가 없습니다.
- 본 프로젝트는 ONE PIECE의 권리자와 무관한 비공식 팬 창작물입니다. 원작 코드, 공식 아트·문구·음악은 제공하거나 포함하지 않습니다.
- 자동 저장은 **현재 브라우저/현재 사이트 주소**의 로컬 저장소에 남습니다. 다른 기기에서 자동 연동되지 않으며 브라우저 데이터를 삭제하면 사라집니다.
- 기존 프로젝트 파일은 현 브랜치에서 새로운 구현으로 교체했습니다. Git 커밋 기록에는 과거 버전이 남아 있습니다.
- 본 프로젝트는 소규모 MVP로, 공식 원작의 모든 지역·사건·인물·능력은 구현하지 않았습니다.
