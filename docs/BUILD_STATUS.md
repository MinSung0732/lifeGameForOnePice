# 첫 항구 시범판 제작 현황

기준일: 2026-11-04. 사용자의 제작 착수 요청에 따라 [기획 검수 기록](PLANNING_GATE.md)을 바탕으로 첫 완주 가능한 경로를 구현했다. **전체 게임의 완성이나 339장 목표 달성을 뜻하지 않는다.**

## 지금 플레이할 수 있는 것

- 출생 전에 원작 모드 또는 더 자유로운 모드를 고르고, 동쪽 바다의 창작 항구에 인간으로 태어난다. 이름·성별 표현·고향 항구·가정 형편은 시드로 추첨된다. 이번 민간 경로는 두 모드 모두 원작 연표를 따른다.
- 출생·유년기의 관찰에서 시작해 배를 잃고, 수리·다른 배의 일·가까운 항구로 떠나는 세 길 중 하나를 고른다. 생업과 항구 조합 가입, 직책, 개인 목표, 후배와의 관계가 이어진다.
- 경고된 구조 선택에 따른 사망, 책임을 넘기는 은퇴, 현재 시점 도달의 세 결말이 있다. 처음의 배·나침반·양육자와 친구가 마지막에 다시 언급된다.
- 관찰 장면은 자동 진행·1/2/4배속·일시정지·수동 다음을 지원한다. 선택 장면에서는 자동 진행이 멈춘다. 브라우저에 여러 생애를 저장하고 이전 생애를 다시 열 수 있다.
- [장면 그림](../design/README.md)은 출생·폭풍·수리·현재 항구·구조 위기·은퇴의 여섯 장이다. 출생 외 그림은 무작위 성별·나이와 충돌하지 않도록 배와 나침반, 먼 뒤태 중심으로 쓴다. 같은 그림을 여러 사건에 사용하는 첫 경로용 시안이며, 무작위 외형과 정확히 일치하는 주인공 그림은 아직 없다.

## 수치와 검사

| 항목 | 현재 |
| --- | ---: |
| 고유 사건 카드 | 49장 |
| 선택 장면 카드 | 13장 |
| 원작 소식 카드 | 2장: 로저 처형과 마린포드 전쟁. 주인공은 현장이 아닌 항구에서 전해 들음 |
| 실제 한 생애의 장면 | 사망 36장 / 은퇴 38장 / 현재 시점 39장 |
| 실제 한 생애의 선택 | 사망 11번 / 은퇴 12번 / 현재 시점 13번 |
| 자동 경로 검사 | 1,000개 시드에서 종료·저장 재현·회차 내 사건 ID 비중복 통과 |
| 연속 10회 장면 겹침 | 바로 전 회차와 85~87% 겹침. 첫 경로의 반복 방지 목표 미달 |

게임 로직은 순수 함수에 가깝게 분리했고, 저장에는 모드·시드·선택 기록만 남긴다. 불러올 때 그 기록으로 삶을 다시 진행해 상태를 복원한다. 잘못된 저장 기록은 지우지 않고, 저장 불가를 화면에 알린다. 원작 소식 카드는 공식 출처 URL을 일지에서 열 수 있다.

시범판의 현재 나이는 66세다. 로저 처형 소식은 현재 기준 24년 전(42세), 마린포드 전쟁 소식은 2년 전(64세)에 놓고 회귀 검사로 고정했다. 인물은 두 사건의 현장에 있지 않으며 소식으로만 듣는다. 항로를 바꾼 상선과 물자 부족은 이 창작 항구의 반응으로 만든 장면이다.

## 다음 제작 범위와 아직 통과하지 못한 기준

1. 어인·밍크·하늘섬 사람·거인의 출생, 각자의 유년기·이동·연령·그림을 별도 원고로 작성한다. 현재 추첨은 인간 출생으로 제한된다.
2. 해군·해적·왕국 수비대·혁명군·정보조직·독립 항해의 가입·직책·전향 경로와 자유로운 모드의 대장·사황 IF를 실제 카드로 만든다. 원작 모드의 고정 직책은 지금도 열리지 않는다.
3. [339장 임시 목표](CONTENT_AUDIT.md)의 배분을 다시 정하고 10회 반복 검수를 통과한다. 첫 항구 경로는 10회 자동 시연에서 인접 회차 장면이 85~87% 겹쳤으므로 아직 다양성 기준을 만족하지 않는다.
4. 40~60분 플레이타임, 모든 그림의 상황 일치, 휴대폰·PC 실제 렌더링, 키보드·화면 읽기 사용성을 사람과 함께 검증한다. 현재 36~39장면의 플레이타임은 측정하지 않았다.
5. 원작 인물의 직접 만남과 추가 세계 사건은 해당 만화 장면·시기·위치를 검증한 뒤 추가한다. 현재 원작 인물 직접 만남 카드는 없다.

픽셀 VFX가 필요한 장면을 구현할 때 프로젝트 안의 [pixelfx 스킬](../.agents/skills/pixelfx/SKILL.md)을 적용한다. 현 시범판에는 픽셀 효과가 없어 라이브러리를 설치하지 않았다.
