# 시범판 제작 현황

기준일: 2026-11-04. 아래 수치는 현재 코드의 **시범판** 기준이며, 기획서의 339장 목표나 40~60분 목표를 달성했다는 뜻이 아니다.

## 현재 플레이 범위

- 원작 모드와 더 자유로운 모드를 출생 전에 토글로 선택한다. 이름·성별(남성·여성)·종족·고향·가정 형편은 항목별로 직접 고르거나 무작위로 둘 수 있다. 이전 시범판의 성별 설정은 저장 기록 재생용으로만 유지한다. 출생 종족은 이후의 소속 선택을 막지 않는다.
- 어린 시절부터 사망까지 한 생애를 본다. 관찰 장면은 남은 시간 게이지와 0.5/0.75/1/2/4배속, 일시정지를 지원한다. 선택을 기다리는 동안에는 시간이 흐르지 않는다. 한 장면 사이에 흐르는 시간은 최대 1년이며, 선택의 여파는 같은 해에 이어질 수 있다.
- 해적·해군·독립 해방 활동·민간 배의 일을 선택하거나 전향한다. 직책 승진과 자유 모드의 조건부 사황·해군 대장 IF가 있다. 원작 모드에서는 확정된 직책을 차지하지 않는다. IF 뒤에는 같은 해의 첫 여파 장면이 이어진다.
- 능력 6개와 성격 5개를 좌우 패널의 100점 게이지로 보여 준다. 선택이 수치와 종합 성향을 바꾼다. 자격이 부족해 실행할 수 없는 선택은 회색이며, 무리한 시도 자체가 가능한 행동은 실패할 수 있다.
- 적대 선단과의 충돌, 우호 기항, 동맹·연합, 약속 파기와 관계 회복, 악마의 열매 발견·보수·거절, 견문색·무장색 수련과 희귀한 패왕색 가능성을 포함한다. 열매 능력자는 물에 잠길 때 더 큰 위험을 감수한다.
- 항로 선택으로 원작의 실제 섬과 지역을 이동하고 최근 기항지를 화면 위에 표시한다. 특정 장소와 시기가 맞으면 도리·브로기, 쿠레하, 크로커스, 레일리, 톰, 야를을 짧게 만날 수 있다. 로저·드래곤·피셔 타이거·샹크스·에이스·흰 수염에 관한 공개 사건은 시기에 맞춰 소식으로 접한다. 직접 만남은 조건부이므로 모든 회차에 나오지는 않는다.
- 여러 생애를 브라우저에 저장하고 다시 열 수 있다. 이전 시범판 저장 기록은 당시의 규칙으로 재현한다. 손상된 저장 기록은 삭제하지 않고 오류를 알린다.
- 주인공 외형을 특정하지 않는 상황 그림을 사용하며, 게임 화면의 왼쪽 그림 아래 설명 문구는 없앴다.

## 코드와 검사 수치

| 항목 | 현재 |
| --- | ---: |
| 저장 기록 호환용 카드 | 133장 |
| 새 생애 전용 작성 카드 | 54장, 그중 선택 카드 30장 |
| 매해 생성 장면 | 연령·소속·상태에 따라 관찰·선택·여행·소식이 추가됨 |
| 조건부 직접 만남 후보 | 6명/쌍 |
| 자동 재생 검사 | 120개 시드에서 종료·연령 증가·저장 재현 확인 |
| Node 테스트 | 14개 통과 |

20개 시드를 각 종족의 첫 번째 가능한 선택으로 재생한 탐색 표본에서는 일반 종족 한 생애에 평균 약 102~104장, 이동 19회, 원작 인물 직접 만남 0.9~2.1회가 나왔다. 거인족은 평균 약 275장, 이동 12회, 직접 만남 0.4회였다. 일반 종족의 관찰 타이머 합계는 1배속에서 평균 약 8.6분, 거인족은 약 35분이다. 선택을 읽고 결정하는 시간은 포함하지 않는다. 표본은 모든 분기와 실제 플레이 시간을 대표하지 않는다.

## 남은 기준

1. 일반 종족은 40~60분 목표에 아직 크게 못 미친다. 짧은 관찰 장면을 늘이기보다 소속·섬·동료·적대 관계의 고유한 선택 사건과 후속 이야기를 더 써야 한다.
2. 최고 직책 IF는 조건부 임명과 첫 여파까지만 있다. 기획서에 적힌 8장짜리 장기 후속 경로와 세계선 전체의 대체 사건은 아직 없다. 왕국 수비대·정보조직 경력, 다른 종족과 출생지도 미구현이다.
3. 현재 섬 이동은 정해진 지역 순환 항로를 선택하는 방식이다. 자유 항해 지도, 원작 인물의 지속 관계, 해류와 기록지침에 따른 세밀한 이동 검증은 더 필요하다.
4. 새 화면의 데스크톱·휴대폰 실제 브라우저 시각 검수는 이번 환경의 자동 승인 사용 한도로 실행하지 못했다. Node 테스트와 정적 코드 검사는 통과했지만, 한 화면 내 배치와 키보드·화면 읽기 경험은 실제 기기에서 확인해야 한다.
5. [339장 임시 목표](CONTENT_AUDIT.md)의 고유 사건 풀은 아직 완성되지 않았다. 한 회차 안의 ID 비중복은 검사했지만, 여러 회차를 반복할 때의 신선도 기준은 별도로 검증해야 한다.

픽셀 VFX가 필요한 장면에는 프로젝트의 [pixelfx 스킬](../.agents/skills/pixelfx/SKILL.md)을 적용한다. 현재는 픽셀 효과가 없어 효과 라이브러리를 설치하지 않았다.
