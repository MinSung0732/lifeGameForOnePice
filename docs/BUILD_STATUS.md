# 시범판 제작 현황

기준일: 2026-11-04. 인간 항구 경로에 네 종족의 창작 생활 경로를 더했다. **전체 게임의 완성이나 339장 목표 달성을 뜻하지 않는다.**

## 지금 플레이할 수 있는 것

- 출생 전에 원작 모드 또는 더 자유로운 모드를 고른다. 이름·성별 표현·종족·고향·가정 형편을 항목별로 직접 고르거나 무작위로 둘 수 있다. 고향은 선택한 종족에 맞는 장소만 고를 수 있다. 두 모드의 현재 민간 경로는 모두 원작 연표를 따른다.
- 인간은 동쪽 바다의 창작 항구에서 배의 손실과 수리, 선원 일, 이동을 겪는다. 어인·밍크족·하늘섬 사람·거인족은 각각 어인섬·조·스카이피아·엘바프의 창작 마을에서 태어나 다른 생활 문제와 생업을 겪는다. 원작의 확정된 인물이나 직책을 대신 차지하지 않는다.
- 직업과 지역 모임 가입, 목표, 위기에서의 선택이 상태에 남는다. 기술·건강·물자·양육자와의 유대·친구와의 유대·지역의 신뢰를 서로 다른 색의 게이지로 본다. 선택 결과에 따라 능력치가 변하며, 부족한 능력치로 일을 시도하면 실패하거나 위험한 결말을 맞을 수 있다.
- 사망·은퇴·현재 시점의 결말이 있다. 66세인 거인족은 아직 성장 중이므로 은퇴 선택이 열리지 않는다. 관찰 장면은 남은 시간 게이지, 1/2/4배속, 일시정지, 수동 다음을 지원한다. 선택 장면에서는 자동 진행이 멈춘다.
- 브라우저에 여러 생애를 저장하고 이전 생애를 다시 열 수 있다. 이전 시범판에서 저장한 인간 생애는 당시 규칙으로 재현한다. 저장 기록을 읽지 못하면 지우지 않고 화면에 알린다.
- [장면 그림](../design/README.md)은 인간 경로 6장과 새 종족 경로의 생활·위기 그림 8장이다. 성별·나이가 정해진 주인공 외형을 강요하지 않도록 생활 공간과 멀리 있는 주민을 중심으로 그렸다.

## 수치와 검사

| 항목 | 현재 |
| --- | ---: |
| 고유 사건 카드 | 133장: 인간 49장 + 다른 종족 각 21장 |
| 선택 장면 카드 | 37장 |
| 실제 한 생애의 장면 | 인간 36~39장 / 다른 종족 15~17장 |
| 자동 경로 검사 | 1,000개 시드에서 종료·저장 재현·회차 내 사건 ID 비중복 통과 |
| 능력치 판정 | 실제 경로에서 기술 부족 실패와 준비된 성공을 각각 검사 |
| 관찰 시간 | 장면 글 길이에 따라 10~22초, 배속과 일시정지 적용 |

로저 처형 소식은 현재 기준 24년 전(주인공 42세), 마린포드 전쟁 소식은 2년 전(64세)에 놓았다. 주인공은 해당 사건의 현장에 있지 않으며 소식을 전해 듣는다. 종족별 고향은 원작에 나온 지역 안의 **창작 마을**이다. 원작 배경 근거는 [어인섬](https://one-piece.com/story/fishman_island/index.html), [조](https://one-piece.com/story/zou/index.html), [스카이피아](https://one-piece.com/story/skypiea/index.html), [엘바프](https://one-piece.com/story/elbaph/index.html) 자료를 참고했다.

## 아직 통과하지 못한 기준

1. 해군·해적·왕국 수비대·혁명군·정보조직 경력, 직책 승진·전향, 더 자유로운 모드의 대장·사황 IF는 구현되지 않았다. 현재 두 모드의 실제 민간 이야기는 같다.
2. 다른 종족의 경로는 15~17장면으로 인간 경로보다 짧다. 모두 합쳐도 40~60분 플레이 목표를 검증하거나 달성했다고 볼 수 없다. 다른 원작 종족과 출신도 아직 포함되지 않았다.
3. 각 종족의 생활·위기 그림 2장을 여러 나이와 사건에 재사용한다. 특정 장면과 외형을 정확히 맞추는 추가 그림이 필요하다. 데스크톱 시작·어인 출생 화면은 1440×900에서 렌더링해 확인했으며, 휴대폰 화면과 키보드·화면 읽기 사용성 검수는 남았다.
4. [339장 임시 목표](CONTENT_AUDIT.md)의 사건 풀이 아직 완성되지 않았다. 같은 종족과 선택을 반복하면 사건이 다시 보이므로 10회 반복 방지 목표는 통과하지 못했다.
5. 원작 인물 직접 만남 카드는 없다. 추가할 때는 만화의 시기·위치·인물을 먼저 검증해야 한다.

픽셀 VFX가 필요한 장면을 구현할 때 프로젝트 안의 [pixelfx 스킬](../.agents/skills/pixelfx/SKILL.md)을 적용한다. 현재는 픽셀 효과가 없어 라이브러리를 설치하지 않았다.
