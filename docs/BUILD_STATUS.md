# 시범판 제작 현황

기준일: 2026-11-04. 아래 수치는 현재 코드의 **시범판** 기준이며, 기획서의 339장 목표나 40~60분 목표를 달성했다는 뜻이 아니다.

## 현재 플레이 범위

- 원작 모드와 더 자유로운 모드를 출생 전에 토글로 선택한다. 이름·성별(남성·여성)·종족·고향·가정 형편은 항목별로 직접 고르거나 무작위로 둘 수 있다. 이전 시범판의 성별 설정은 저장 기록 재생용으로만 유지한다. 출생 종족은 이후의 소속 선택을 막지 않는다.
- 어린 시절부터 사망까지 한 생애를 본다. 관찰 장면은 남은 시간 게이지와 0.5/0.75/1/2/4배속, 일시정지를 지원한다. 선택을 기다리는 동안에는 시간이 흐르지 않는다. 한 장면 사이에 흐르는 시간은 최대 1년이며, 선택의 여파는 같은 해에 이어질 수 있다.
- 유년기의 견습 출항·해군 교육·구호 연락망, 성인기의 해적단·해군·독립 해방 활동·민간 배·고향 일을 선택한다. 이후에는 정해진 나이의 이직 버튼 대신 경력 기간·지역의 신뢰·구조·항해·적대 경험에 따라 전향·다른 해적단 영입·독립 선장·혁명군 제안이 열린다. 직책 승진은 숙련과 신뢰가 쌓였을 때 제안되며 거절할 수 있다. 자유 모드의 조건부 사황·해군 대장 IF와 같은 해 첫 여파가 있으며, 원작 모드에서는 확정된 직책을 차지하지 않는다.
- 능력 6개와 성격 5개를 좌우 패널의 100점 게이지로 보여 준다. 선택이 수치와 종합 성향을 바꾼다. 자격이 부족해 실행할 수 없는 선택은 회색이며, 무리한 시도 자체가 가능한 행동은 실패할 수 있다.
- 적대 선단과의 충돌, 우호 기항, 동맹·연합, 약속 파기와 관계 회복, 악마의 열매 발견·보수·거절, 견문색·무장색 수련과 희귀한 패왕색 가능성을 포함한다. 열매 능력자는 물에 잠길 때 더 큰 위험을 감수한다.
- 항로 선택으로 원작의 실제 섬과 지역을 이동하고 최근 기항지를 화면 위에 표시한다. 특정 장소와 시기가 맞으면 도리·브로기, 쿠레하, 크로커스, 레일리, 톰, 야를, 엘바프의 루피를 짧게 만날 수 있다. 로저·드래곤·피셔 타이거·샹크스·에이스·흰 수염에 관한 공개 사건은 시기에 맞춰 소식으로 접한다. 직접 만남은 조건부이므로 모든 회차에 나오지는 않는다.
- 새 생애는 종족별 게임용 시작 능력에 시드로 정한 개인차를 더한다. 출생 시점이 다양하며, 원작 현재는 연표 기준점이지 사망 시점이 아니다. 이후의 개인 장면은 미공개 원작 미래를 확정하지 않는다. 이전 저장 기록은 당시 출생·수명 규칙으로 재생한다.
- 여러 생애를 브라우저에 저장하고 다시 열 수 있다. 이전 시범판 저장 기록은 당시의 규칙으로 재현한다. 손상된 저장 기록은 삭제하지 않고 오류를 알린다.
- 거인족의 조용한 해에는 거인 전용 일상 장면 230개(유년 80·바다 일 90·고향 30·노년 30)를 공용 장면보다 먼저 쓴다. Gemini로 초안을 쓰고 1인칭·성별·원작 규칙을 검수했다. 새 출생 규칙의 거인에게는 거인 전용 선택 사건 44개(유년 14·성인 30)도 공용 6종보다 먼저 나온다. 이전 출생 규칙 기록은 같은 선택지로 재생된다. 60개 시드 자동 재생에서 거인 생애의 같은 제목 재등장은 평균 167회에서 28회로 줄었고, 남은 반복은 같은 섬의 재출항, 다시 오는 이직·승급 제안, 한 바퀴 돈 일상 장면이다.
- 주인공 외형을 특정하지 않는 상황 그림을 사용하며, 게임 화면의 왼쪽 그림 아래 설명 문구는 없앴다.

## 코드와 검사 수치

| 항목 | 현재 |
| --- | ---: |
| 저장 기록 호환용 카드 | 133장 |
| 새 생애 전용 작성 카드 | 54장, 그중 선택 카드 30장 |
| 매해 생성 장면 | 연령·소속·상태에 따라 관찰·선택·여행·소식이 추가됨 |
| 조건부 직접 만남 후보 | 7명/쌍 |
| 자동 재생 검사 | 120개 시드에서 종료·연령 증가·저장 재현·최근 10장면 제목 비반복 확인 |
| Node 테스트 | 19개 통과 |

별도 탐색에서 다섯 종족·두 모드를 섞은 100개 시드를 진행 순서에 따라 가능한 선택을 순환하며 재생했다. 전부 사망으로 완결됐고, 장면 ID 순서가 서로 다른 생애는 96개였다. 원작 인물과의 직접 만남은 총 103회, 원작 현재를 지나 산 생애는 71회였다. 최근 10장면 안에 같은 제목이 다시 나온 사례는 없었다. 이는 자동 선택 표본이며 실제 이용자가 느끼는 서사의 다양성이나 플레이 시간을 보증하지 않는다.

## 남은 기준

1. 일반 종족의 실제 40~60분 플레이 목표는 아직 검증·달성하지 못했다. 짧은 관찰 장면을 늘이기보다 소속·섬·동료·적대 관계의 고유한 선택 사건과 후속 이야기를 더 써야 한다.
2. 최고 직책 IF는 조건부 임명과 첫 여파까지만 있다. 기획서에 적힌 장기 후속 경로와 세계선 전체의 대체 사건은 아직 없다. 왕국 수비대·정보조직·독립 현상금 사냥 경력, 다른 종족과 출생지도 미구현이다.
3. 현재 섬 이동은 정해진 지역 순환 항로를 선택하는 방식이다. 자유 항해 지도, 원작 인물의 지속 관계, 해류와 기록지침에 따른 세밀한 이동 검증은 더 필요하다.
4. 새 화면의 데스크톱·휴대폰 실제 브라우저 시각 검수는 이번 환경의 자동 승인 사용 한도로 실행하지 못했다. Node 테스트와 정적 코드 검사는 통과했지만, 한 화면 내 배치와 키보드·화면 읽기 경험은 실제 기기에서 확인해야 한다.
5. [339장 임시 목표](CONTENT_AUDIT.md)의 고유 사건 풀은 아직 완성되지 않았다. 한 회차 안의 ID 비중복은 검사했지만, 여러 회차를 반복할 때의 신선도 기준은 별도로 검증해야 한다.

픽셀 VFX가 필요한 장면에는 프로젝트의 [pixelfx 스킬](../.agents/skills/pixelfx/SKILL.md)을 적용한다. 현재는 픽셀 효과가 없어 효과 라이브러리를 설치하지 않았다.
