# Scene art library

75 original, self-contained SVG illustrations: 25 incident types × 3 day/dusk/night variants.

The story engine selects a scene category from the event and rotates across three compositions. No hotlinked anime screenshots or unlicensed images are used. Images can be replaced individually with owned/licensed artwork using the same filenames.

Categories: birth, home, school, harbor, village, dojo, friends, festival, market, island, ship, marine, pirate, revolution, bounty, map, grandline, treasure, clinic, farewell, legacy, storm, battle, fruit, night.
